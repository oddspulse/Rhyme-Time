# 🎵 Rhyme Time - Web Version

> Say the word on beat! Viral rhythm game built with Next.js.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npm i -g vercel
vercel
```

Or click: [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

## 🎮 How to Play

1. Tap highlighted cards on the beat
2. Perfect timing = ±80ms
3. 3 lives, 16 beats per round
4. BPM increases!

Built with Next.js 15, React 19, Tailwind CSS, Framer Motion.
